# UI font

Inter Variable 4.1, upright, from the official Inter distribution:
https://rsms.me/inter/font-files/InterVariable.woff2?v=4.1

License: `Inter-LICENSE.txt` (SIL Open Font License 1.1).
Source: https://rsms.me/inter/

Served locally as the CSS family `Axial UI` for controls, dialogs and board labels.
The existing brand font stack remains separate. Normal text uses 400, tutorial
body copy 500, supporting labels 600 and emphasized labels/headings 700.
