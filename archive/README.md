# Archive

Axial started in late 2025 as a Unity desktop game with hand-tracking controls and a Python AI opponent, built as a joint project for two university courses. The browser game in [`axial-web/`](../axial-web/) replaced it. Nothing in this folder is a dependency of the web app; it's kept as a record of where the project came from.

| Folder                                   | Contents                                                                                 |
| ---------------------------------------- | ---------------------------------------------------------------------------------------- |
| [`original-project/`](original-project/) | The project proposal, the LaTeX sources for the two course reports, and a gameplay video |
| [`python-ai/`](python-ai/)               | The Numba-accelerated MCTS engine that powered the Unity game, plus training experiments |

The compiled reports are in [`docs/papers/`](../docs/papers/README.md). The Unity project is in [`axial-unity/`](../axial-unity/README.md), without the MediaPipe plugin it embeds.
